etl.s3 module¶

Common code around interacting with AWS S3.

class etl.s3.S3Uploader(bucket_name, callback=None, dry_run=False)[source]¶

Bases: object

Upload files from local filesystem into the given S3 folder.

etl.s3.delete_objects(bucket_name, object_keys, wait=False, hdfs_wait=False, _retry=True, dry_run=False)[source]¶

For each object key in object_keys, attempt to delete the key and its content from an S3 bucket.

If the optional parameter “wait” is true, then we’ll wait until the object has actually been deleted. If optional parameter “hdfs_wait” is true, we will confirm each key’s removal using hdfs ls.

Return type

None
