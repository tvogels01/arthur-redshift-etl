etl.config.settings module

etl.config.settings module¶

etl.config.settings.show_value(name, default)[source]¶

Show value of a specific variable.

This fails if the variable is not set and no default is provided.

This is a callback of a command.

Return type

None

etl.config.settings.show_vars(names)[source]¶

List “variables” with values.

This shows all known configuration settings as “variables” with their values or just the variables that are selected.

This is a callback of a command.

Return type

None
