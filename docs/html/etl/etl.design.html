static make_item_sorter()[source]¶

Return function that allows sorting keys that appear in any “object” (JSON-speak for dict).

The sort order makes the resulting order of keys easier to digest by humans.

Input to the sorter is a tuple of (key, value) from turning a dict into a list of items. Output (return value) of the sorter is a tuple of (preferred order, key name). If a key is not known, it’s sorted alphabetically (ignoring case) after all known ones.
